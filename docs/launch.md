## Threads · 한국어

웹사이트 안에 작은 데스크톱을 넣고 싶어서 dindbOS를 만들었습니다.

React 컴포넌트를 앱처럼 열고, 창을 움직이고, Dock에 넣을 수 있어요. Files·TextEdit·Terminal도 같은 파일과 상태를 사용합니다. 테마와 UI는 바꾸고, 창과 앱의 수명주기는 SDK에 맡길 수 있습니다.

포트폴리오 전체를 바꾸거나, 페이지 한 구역에만 넣어도 됩니다. React / Vanilla 스타터와 에이전트용 가이드도 함께 준비했습니다.

## English

I built a desktop you can put inside a website.

Bring a React component, open it as an app, and give it a window and a place in the Dock. Files, TextEdit, Terminal, and your apps share one browser runtime. Customize the theme or replace the shell UI.

Full-page portfolio or one embedded section. React and Vanilla starters included.

Source: https://github.com/Dindb-dong/dindbos
