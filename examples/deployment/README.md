# Deployment Recipes

These files are copyable starting points for SDK host apps.

- `netlify.toml`: origin-isolated Netlify static deployment.
- `static-headers.txt`: generic headers for nginx, Caddy, custom static servers, or CDN rules.
- `github-pages.md`: degraded-mode expectations for GitHub Pages.
- `local-dev.md`: local dev expectations and verification commands.

Run `npm run smoke:deployment-recipes` to verify these recipes stay aligned with release evidence.
